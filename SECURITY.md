# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

Only the latest release receives security updates.

---

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues.

**Email us at:** security@thred.qzz.io

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Your suggested fix (optional)

---

## What to Expect

- You'll receive acknowledgement within **48 hours**
- We'll investigate and keep you updated on our progress
- We'll notify you when the fix is released
- Credit will be given in the changelog if you want it

---

## Scope

### In scope

- Security bugs in Thred's Electron main process
- Webview sandbox escape vulnerabilities
- Local data exposure or unauthorized access
- IPC channel abuse between main and renderer

### Out of scope

- Vulnerabilities in third-party AI services (ChatGPT, Claude, etc.)
- Issues requiring physical access to the machine
- Social engineering attacks

---

Thank you for helping keep Thred safe.
